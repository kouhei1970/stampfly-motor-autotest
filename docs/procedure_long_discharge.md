# 長時間放電による等価抵抗 R_out の電池電圧依存の測定（手順書）

作成 2026-10-30、更新 2026-11-02（推力を主な測定量にした。プロペラなしの段を加えた）。状態: 計画（未実施）。

## 1. 目的

StampFly の駆動回路（モータに並列のコンデンサ $C_C$ で還流する構成）は、1 周期で平均すると、電池電圧と逆起電力の間に等価抵抗 $R_\text{out}(D, C_C)$ が入った形で表せる。

$$\bar I_m = \frac{V_{DD} - K_e\,\omega}{R_\text{out}(D, C_C)}$$

この式は「$R_\text{out}$ は電池電圧によらない」ことを前提にしている。ところが 2026-10-15 のベンチは電池電圧 4.17〜4.38 V だけで、この前提を確かめた範囲は狭い。また飛行ログでは、ホバリングに要る Duty の電池電圧への依存が、この前提からの予測の半分ほどしか出なかった。

この試験では、満充電の電池でモータを約 4 分間回し続け、電池電圧が下がっていく間に $R_\text{out}$ を繰り返し測る。電源装置は使わない（電池と内部インピーダンスや応答が違い、結果が変わるおそれがあるため）。あわせて、ホバリング付近（Duty 0.6〜0.8）の $R_\text{out}(D)$ を 0.02 刻みで実測し、シミュレータ（SILS）の基準表を更新する。さらに、Duty を段差状に変えたときの回転数の動き（駆動中の過渡）を測る。2026-10-15 のデータにある過渡は駆動を切った後のスピンダウンだけで、駆動中の過渡はない。

推力も主な測定量として測る。最終的には電池電圧と推力の関係を明らかにしたいので、各点の推力・電圧・電流・回転数を同時にそろえ、後日の検討や同定に使えるデータにする。

あわせて、$R_\text{out}$ が $\omega$ にもよらないことを確かめる。前の式の前提では $\omega$ は分子の逆起電力 $K_e\omega$ にだけ入り、$R_\text{out}$ は $D$ と回路の定数（$C_C$、モータの $L$・$R$、PWM 周波数）だけで決まる。2026-10-15 のプロペラ付きの掃引では各 Duty で $\omega$ が 1 つしかなく、Duty の効果と $\omega$ の効果を分けられない。プロペラなしの掃引（Duty 0.1〜0.6）と比べると、同じ Duty で $\omega$ が 1.8〜2.9 倍のとき $R_\text{out}$ は 0.98〜0.81 倍だった。ただしプロペラなしでは分子 $V_{DD}-K_e\omega$ が小さく、$K_e$ が 1 % 違うだけで $R_\text{out}$ が 2〜10 % 動く（Duty 0.2〜0.6）。約 2 % の $K_e$ のずれでもほぼ説明できるため、判別できていない。今回は、同じ日・同じ電池・ほぼ同じ電圧で、プロペラなしと付きの段を続けて測り、$K_e$ も同じ日にスピンダウンで求める。

## 2. 測る量と求め方

| 量 | 測り方 | 備考 |
|---|---|---|
| $V_{DD}$（基板の電池側の電圧） | オシロ CH2、基板近くのケーブル分岐。1 回の取り込みの平均 | 解析の入力。電池の内部抵抗による低下はこれに含まれる |
| ドレイン電圧 $v_D$ | オシロ CH1 | 実測 Duty と回転数の計算に使う |
| 角速度 $\omega$ | PWM 1 周期ごとの $V_{DD}-v_D$ の平均を FFT し、脈動の周波数 $f$ から $\omega = 2\pi f / N$（$N = 10$） | 2026-10-15 と同じ方法 |
| 電池電流 $I_\text{bat}$ | CLI の `sensor power`（シャント修正後のファーム） | 構成 A では平均の電池電流 = 平均のモータ電流 |
| モータ缶の温度 | 熱電対はない。非接触温度計があれば、止めたときに缶を測る | 巻線抵抗は 1 K あたり約 0.4 % 変わる。温度計がないときは、9 章の巻線抵抗の目安で温度の変化を見る |
| 推力 | 秤の表示を USB カメラで連続撮影（時刻付き、1 秒に約 3 枚）し、数字を自動で読み取る | ゼロは運転の前後と、測定 B の周回の切れ目（60 秒ごと）に止めて取り、その間は直線でつなぐ（2026-10-15 は 11 分でゼロが 0.66 → 0.97 g と、ほぼ一方向にずれた）。各段の後半の読みを使う |
| モータ端子間の平均電圧 $\langle v_m\rangle$ | オシロの $V_{DD}-v_D$ を PWM 1 周期ごとに平均 | 2026-10-15 と同じ |
| $K_e$ | プロペラなしのスピンダウン（電流 0）で、端子電圧と脈動の周波数から $K_e = v_m/\omega$ | 同じ日に求める。$R$・電流・ブラシの電圧降下によらない |
| 回転数（音、任意） | 運転の間ずっと録音し、1 回転の線（羽根 4 枚の通過は 4 倍の線）を FFT で追う | オシロは 1 回 48 ms しか見えないので、その間を埋める確認用 |

各測定点で次を計算する（$K_e = 5.905\times10^{-4}$ V·s/rad）。

$$R_\text{out,meas} = \frac{V_{DD} - K_e\,\omega}{I_\text{bat}}$$

Duty は指令値（ファームと SILS が受け取る値）で整理し、実測 Duty も併記する。

## 3. 判定（測る前に決めておく）

| 比べるもの | 前提「$R_\text{out}$ は電池電圧によらない」が正しければ | 正しくなければ |
|---|---|---|
| 同じ Duty の「冷えた状態・高い電圧」（開始直後）と「冷えた状態・低い電圧」（冷却後の再測定） | 差は繰り返しのばらつき程度（目安 ±2 %） | 電圧の差に応じて系統的に違う。1 V あたり何 % かを出す |
| 同じ Duty の「熱い状態・低い電圧」（4 分の終わり）と「冷えた状態・低い電圧」 | 差は温度の効果だけで、巻線抵抗の温度係数から見積もれる大きさ | — |
| 4 分間の連続データの $R_\text{out}$ 対 $V_{DD}$ | 温度の目安（巻線抵抗、または停止時の缶の温度）で補正すると傾きがほぼ 0 | 補正後も傾きが残る |
| 同じ Duty のプロペラなしと付き（測定 E）の $R_\text{out}$ の比。$K_e$ は同じ日のスピンダウン（E3）の値 | Duty 0.2・0.3・0.4 の 3 点すべてで、比が 1 から ±3 % 以内（この $\omega$ の範囲では $\omega$ によらない） | 3 点とも同じ向きに 5 % 以上ずれる。$\omega$ 1000 rad/s あたり何 % かを出す。どちらでもなければ判定保留。Duty 0.5・0.6 は $K_e$ の誤差が 8〜10 倍に効くので参考に留める |
| 推力と回転数（測定 E・A・B・C の全点） | 電圧・温度の違う点が 1 本の曲線 $F(\omega)$ に乗り、残差が ±2 % 以内（推力は $\omega$ だけで決まり、電圧は $\omega$ を通してだけ効く） | 同じ $\omega$ で、電圧や温度によって推力が系統的に違う |
| Duty ステップでの $\omega(t)$ と、非線形の式を数値で解いた軌道（9 章） | 正規化した軌道 $(\omega-\omega_0)/(\omega_1-\omega_0)$ の差が、段差の間ずっと 0.1 以内 | 差が 0.1 を超える。速い・遅いのどちら向きか、どの段差（上げ・下げ・大小）で起きるかを出す |

## 5. 安全

- プロペラ付きで約 4 分回す。保護具を使い、機体を固定し、回転面に手や線を近づけない。
- 次のどれかになったら、すぐ `motor stop` で止める。
  - 負荷中の $V_{DD}$ が 3.5 V を下回った
  - 止めたときの缶の温度が、あらかじめ決めた上限（例: 70 °C）を超えた（非接触温度計がある場合）。温度計がなければ、総時間 240 秒を守る
  - 異音、焦げたにおい、機体の動き

## 6. 手順

### 準備

1. 室温、電池の番号、電池の無負荷電圧を記録する。
2. モータが冷えていること（前の運転から 10 分以上たっている。非接触温度計があれば、缶の温度 ≒ 室温）を確かめる。
3. 配線をつないだ状態で秤のゼロを合わせ、ゼロの読みを記録する。
4. シリアル中継を起動する（別のターミナルで常駐）。

```bash
python3 tools/sf_serial_bridge.py
```

5. 別のターミナルで環境変数を設定する。

```bash
export SCOPE_IP=<オシロの IP>
export AUTOTEST_DATA=./data/long_discharge_<日付>_bat<番号>
export SF_CURRENT_SCALE=1
```

### 測定 E: プロペラなしと付きの同じ Duty（$\omega$ への依存、最初に行う）

満充電の電池・冷えたモータで、プロペラなしと付きの段を続けて測る。電圧の差を小さく保つため、間にほかの測定を挟まない。1 段ごとに止めて前後のゼロを取る 2026-10-15 の方式（`exp_auto.py`）をそのまま使う。

E1. プロペラを外す。秤のゼロの読みを記録する。モータが止まった状態で、テスターでプローブの点の $V_{DD}$ を測り、オシロの CH1・CH2 の平均と比べる（電流が流れていないので、ドレインも $V_{DD}$ に等しい）。

E2. プロペラなしの掃引。

```bash
DUTIES="20 30 40 50 60" tools/exp_batch.sh 1 np02
```

E3. プロペラなしのスピンダウン（$K_e$ を求める。プロペラなしは 0.1 s/div）。

```bash
python3 tools/exp_coast.py coast_np_d60_ke 60 4 0.1 --motor 1
```

E4. プロペラを付ける。秤のゼロの読みを記録する。

E5. プロペラ付きの掃引（E2 と同じ Duty）。

```bash
DUTIES="20 30 40 50 60" tools/exp_batch.sh 1 c02
```

E6. 電池の無負荷電圧（温度計があれば缶の温度も）を記録し、測定 A へ進む。

### 測定 A: 開始直後（冷えた状態・高い電圧）

6. Duty 周回を 1 周だけ測る（7 の周回と同じ Duty 列）。連続撮影の写真から、各段で秤の読みが落ち着くまでの時間を確かめる。段の頭から 3 秒以内に落ち着かなければ、測定 B の各段の時間を延ばす（例: 7 秒）。

### 測定 B: 約 4 分間の連続運転

7. 次の Duty 列を、止めずに繰り返す。各段 5 秒、各段で 1.5 秒待ってからオシロを取り込み（数秒かかる）、`sensor power` を読む。

| 順 | Duty [%] |
|---|---|
| 1〜12 | 50, 60, 62, 64, 66, 68, 70, 72, 74, 76, 78, 80 |

   1 周 60 秒で、4 分間で 4 周になる。指令は `motor test 1 <Duty%> 7`（7 秒）を各段の頭に送る。新しい指令が前の指令をその場で置き換えるので、段の切り替えでモータは止まらない（1 回の指令の上限は 60 秒）。

   各周の終わりに `motor stop` で 4 秒止め、秤のゼロを撮る（止めてから 2.5 秒以降の写真を使う）。止めている時間は総時間に数えない。4 秒の停止は缶の温度にはほとんど効かない。電池の電圧は少し戻るが、$V_{DD}$ は各点で測るので問題ない。
8. 240 秒たつか、5 章の停止条件に当たったら `motor stop` で止める。止めた時刻を記録する（温度計があれば缶の温度も）。

### 測定 C: 冷却後（冷えた状態・低い電圧）

9. 電池はつないだまま、モータだけを止めて冷ます。10 分待つ（温度計があれば、缶の温度が室温 +2 °C 以内に戻るまで）。待ち時間を記録する。冷えたかどうかは、解析で巻線抵抗の目安が測定 A の値に戻っているかでも確かめる。
10. 6 と同じ Duty 周回を 1 周だけ測る。電池は休ませた分だけ電圧が少し戻るが、$V_{DD}$ は各点で測るので問題ない。
11. 秤のゼロの読みを記録する。

### 低い電圧までの繰り返し（2026-11-02 追加）

11a. 測定 C の後、同じ電池で「測定 B（4 分）→ 10 分冷ます → 測定 C（1 周）」を、負荷時の $V_{DD}$ が 3.6 V 付近になるまで繰り返す（3〜4 回、約 1 時間の見込み）。1 回の 4 分（1 モータ、平均約 0.95 A、約 60 mAh）では負荷時の $V_{DD}$ が約 4.2 → 3.9 V しか動かず、飛行で使う範囲（3.5〜4.2 V）に届かないため。1 回の運転を長くするより、冷ましながら繰り返すほうが、温度計がないときのモータの温度を管理しやすい。

### 繰り返し

12. 2 本目の電池で 1〜11 を繰り返す。このとき Duty 列を逆順（80 → 50）にして、順番の影響を見る。Duty の指定は整数の % だけ（ファームの `motor test` の仕様）。

### 測定 D: Duty ステップ（駆動中の過渡）

推力の過渡は、この構成では測れない（秤の応答が遅く、落ち着くまで数秒かかる。カメラも 1 秒に約 3 枚）。そこで、ここで測る $\omega(t)$ と、定常の測定（E・A・B・C）で求めた $F(\omega)$ から、推力の過渡を $F(t) = F(\omega(t))$ と推定する。空力が回転数の変化に遅れなく追従するとみなしており、この仮定は確かめていない。推力の過渡を直接測るには、応答の速いロードセルとアンプを使い、オシロの空いているチャネル（CH3・CH4）で記録する別の構成が要る（機体を載せる台の機械的な共振が、測りたい帯域より十分高いことも必要）。

回転の式は $\omega$ について非線形なので、過渡は時定数では整理しない。実測の $\omega(t)$ と、同じ指令 Duty と実測の $V_{DD}(t)$ を入れて非線形の式を数値で解いた軌道を比べる（9 章）。

長時間放電の基準点（冷えた状態・高い電圧）を乱さないよう、次の 2 回に分けて行う。

| 回 | いつ | 電池 |
|---|---|---|
| D-低 | 測定 C の直後（モータは冷えた状態から始まる） | 長時間放電に使った電池（電圧が低い） |
| D-高 | 別の日、または長時間放電の前に、モータが冷えた状態で | 別の満充電の電池 |

13. オシロを長時間の取り込みに設定する。

| 設定 | 値 |
|---|---|
| 時間軸 | 100 ms/div（画面 12 div で約 1.2 秒） |
| メモリ長 | 2 チャネルで最大（12 Mpts。約 10 MS/s、PWM 1 周期あたり約 66 点） |
| トリガ | 単発。PC から強制トリガ（`:TFORce`）をかけ、記録の先頭から約 0.1 秒後に段差が来るようにする |
| チャネル | CH1 ドレイン、CH2 $V_{DD}$（ほかの測定と同じ） |

14. 次の段差を順に行う。各段差の前に、段差前の Duty で 2.5 秒以上回して定常にしてから、強制トリガ → 約 0.1 秒後に段差後の Duty の `motor test` を送る。取り込みの読み出し中も、モータは段差後の Duty のまま回してよい（読み出しが終わったら次の段差の段差前の Duty へ移る）。

| 番号 | 段差前 → 段差後 [%] | 見るもの |
|---|---|---|
| S1 | 0 → 60 | 回し始め（止まった状態から） |
| S2 | 60 → 68 | ホバリング付近の小さな上げ |
| S3 | 68 → 60 | 同じ幅の下げ |
| S4 | 50 → 80 | 大きな上げ |
| S5 | 80 → 50 | 大きな下げ |
| S6 | 60 → 0 | 駆動を切った後の減速（10-15 のスピンダウンとの照合） |

15. 段差の時刻は、PC の送信時刻ではなく、ドレイン波形で PWM の幅が変わった周期から決める（シリアルの遅れを含まないようにするため）。
16. 各段差の取り込みの前後に `sensor power` を読む（温度計があれば缶の温度も記録する）。

| 停止 | 停止の理由、時刻 |
| Duty ステップ | 回（D-低・D-高）、段差の番号、段差前後の Duty、段差の時刻（波形から）、取り込みの前後の $V_{DD}$・電流、波形ファイル名 |

## 8. 必要なスクリプト（`tools/exp_long.py`、未作成）

既存の `tools/exp_auto.py` は 1 段ごとに止めて前後の読みを取る作りなので、連続運転用を別に作る。必要な動きは次のとおり。

| 機能 | 内容 |
|---|---|
| Duty 周回 | Duty 列・各段の時間・総時間・周回数を引数で受け、各段の頭に `motor test 1 <Duty%> <段の時間 + 2>` を送る |
| 取り込み | 各段で待ち時間の後にオシロの 2 チャネルを取り込み、$\omega$・実測 Duty・$V_{DD}$ の平均を計算する（`exp_rpm.py` の計算を流用） |
| 電流 | 各段で `sensor power` を 1〜2 回読む |
| 撮影 | カメラを開いたままにして連続で撮る（1 秒に約 3 枚）。各写真に PC の時刻（0.01 秒単位）を付ける。今の `exp_auto.py` のように毎回カメラを起動すると、1 回に 4.5 秒かかり（2026-11-02 に計測）、5 秒の段に収まらない |
| ゼロ | 測定 B の各周の終わりに `motor stop` で 4 秒止め、次の周の頭で再開する |
| 録音（任意） | 運転の間ずっと録音し、録音の開始時刻を記録する |
| 送信時刻 | コマンドを送った時刻を 0.01 秒単位で記録する（今の中継のログは秒単位） |
| 数字の読み取り | 秤の 7 セグメントの数字を自動で読む。カメラは固定なので、各桁の 7 つの区画の位置を最初に 1 回決め、区画の明暗で数字を判定する。表示の切り替わり中で読めない写真は除く。一部の写真を目で読んで照合し、読み違いの率を出す |
| 温度の目安 | 各点で巻線抵抗の目安を計算して記録する（温度計はない。9 章） |
| 停止 | $V_{DD}$ の下限と総時間で自動停止し、Ctrl-C でも必ず `motor stop` を送る |
| 出力 | 1 点 1 行の CSV（7 章の項目）と、取り込んだ波形の要約 |
| Duty ステップ | 段差の列を引数で受け、段差前の Duty で待つ → オシロを単発・長時間の設定にして強制トリガ → 段差後の Duty を送る → 波形を全点読み出す、を繰り返す |
| 過渡の計算 | PWM 1 周期ごとに $V_{DD}-v_D$ の平均・$V_{DD}$ の平均・実測 Duty を求め、その系列の脈動の周波数をずらしながら（例: 窓 10 ms、刻み 2 ms）求めて $\omega(t)$ にする。より細かく見るときは、脈動の 10 周期（1 回転）ごとにかかった時間から $\omega$ を求める（ホバリング付近の 3600 rad/s では 1 回転 1.7 ms ごとに 1 点）。回し始めの直後は脈動の周波数が低く振幅も小さいので、最初の数回転は追えない。段差の時刻は実測 Duty の変化点から決める |

## 9. 解析と結果の使い道

1. 各点の $R_\text{out,meas}$ を計算し、Duty ごとに $V_{DD}$ と温度の目安に対して並べる。温度の目安は巻線抵抗 $R_w = (\langle v_m\rangle - K_e\,\omega)/I_\text{bat}$ とする（銅は 1 K あたり約 0.39 %）。ただし磁石の温度で $K_e$ も少し変わり、その分と区別できないので、目安に留める。
2. 3 章の比較を行い、「電圧の効果」を 1 V あたりの %、「温度の効果」を巻線抵抗の目安の変化 1 % あたりの % で出す。
3. 電圧の効果がない場合: 0.02 刻みの $R_\text{out}(D)$ を SILS の基準表に入れる（今の表は 0.1 刻みの 9 点を元にしている）。
4. 電圧の効果がある場合: $R_\text{out}(D, V_{DD})$ として表を 2 次元にし、ファームの推力 → Duty 変換に使う前に影響を見積もる。論文の改訂では、電圧によらないことを確かめた範囲を明記する。
5. Duty ステップ: 段差の時刻から、指令 Duty の段差と実測の $V_{DD}(t)$ を入れて、次の式を段差前の定常の $\omega$ から数値で解く（$R_\text{out}$ は同じ回の実測を使う）。

$$J\,\dot\omega = K_t\,\frac{V_{DD}(t) - K_e\,\omega}{R_\text{out}(D(t))} - C_Q\,\omega^2 - K_t\,I_0(\omega)$$

   実測と計算の軌道を、段差前後の定常値で正規化して重ね、3 章の基準で判定する。S6（駆動を切った後）は、10-15 のスピンダウンと同じ形になるかも確かめる。合わない場合は、どの項（慣性 $J$、電気的な制動 $K_tK_e/R_\text{out}$、空力・摩擦）を変えれば合うかを、段差の向きと大きさごとの食い違い方から調べる。時定数の当てはめは行わない（線形化した時定数が意味を持つのは、動作点のまわりの小さな変化だけ）。
6. $K_e$: E3 のスピンダウンで、窓をずらしながら脈動の周波数から $\omega(t)$ を求め、同じ窓の端子電圧の平均 $v_m(t)$ との比から $K_e$ を出す（電流 0 なので $v_m = K_e\omega$）。2026-10-15 の値 5.905e-4 と比べる。
7. $\omega$ への依存: E2 と E5 の同じ Duty の $R_\text{out}$ を、6 の $K_e$ で計算して比べ、3 章の基準で判定する。
8. 推力: 自動で読んだ値から、直線でつないだゼロを引く。全点の $F$ を $\omega$ に対して並べ、3 章の基準で 1 本の曲線に乗るかを見る。あわせて、Duty ごとに $F$ の $V_{DD}$ に対する傾き（1 V あたりの %）を出し、同じ回の $R_\text{out}$ と $C_T$ を使った式からの予測と比べる。飛行ログで見たホバリング Duty の電圧依存（1 章）とも照合する。
9. 結果は stampfly_ecosystem の `analysis/notes/ct_cq_bench_20261015.md`（8 章「残る課題」）に反映する。
